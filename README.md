# AI Resume Analyzer

**Tech Stack:** MERN (MongoDB, Express, React, Node.js)

---

## Project Description

AI Resume Analyzer is a full-stack web application that allows users to manage resumes efficiently. Users can **add, edit, delete, and update** resumes. The app also includes a **basic AI skill analysis** feature that scores resumes based on predefined skills.

---

## Features

- **Add Resume:** Fill out name, email, and skills to save a new resume.
- **Edit Resume:** Update existing resume details with ease.
- **Delete Resume:** Remove a resume from the database.
- **AI Skill Analysis:** Analyze the skills in a resume and get a matching score.
- **MongoDB Integration:** All resume data is stored and managed in MongoDB collections.
